🌐 Deployment ke Joomla

Opsi Rekomendasi: Subfolder dengan Menu Link

Langkah-langkah:

  1. Upload semua file dari folder /dist ke server Joomla
  2. Path server: /public_html/kanwil/sumsel/id/ragit-dobel-4-0/
  3. Buat file .htaccess untuk React Router
  4. Tambah menu item di Joomla Admin Panel (di bawah menu "Inovasi")
  5. Test URL production
URL Production:
https://djpb.kemenkeu.go.id/kanwil/sumsel/id/ragit-dobel-4-0/

.htaccess Configuration

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /kanwil/sumsel/id/ragit-dobel-4-0/
  
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /kanwil/sumsel/id/ragit-dobel-4-0/index.html [L]
</IfModule>
